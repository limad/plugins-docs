# Changelog Modbus Monitor

## Version under development

### 09/11/2026

- **Security and reliability**: widgets installed with the plugin come from a fixed version and are checked before installation.

### 08/11/2026

- **Security and reliability**: widgets are only downloaded when they have changed; your custom widgets are never overwritten; clearer log message when the download fails.

### 29/10/2026

- **Interface**: "Management - Modbus Monitor" title on the plugin page; Documentation and Community tiles moved to the end.

### 23/10/2026

- **New features and fixes**: translations updated.

### 17/10/2026

- **Security and reliability**: the plugin page works with the browser's strengthened protections.

### 15/10/2026

- **New features and fixes**: default widget applied to new commands; "Default config" button to reapply it to all commands of an equipment.

### 20/09/2026

- **New features and fixes**: reading cycle adjustable per equipment (30 s to 5 min); import and export of a complete equipment (configuration and commands); "Raw information" button; compact command table with edit mode; Scan and Tester windows reworked, with command creation from the tester; neighbouring registers read in a single request.
- **Security and reliability**: import and export only apply to Modbus Monitor equipment; imported files are deleted after import; a write command shows an error instead of a false success.
