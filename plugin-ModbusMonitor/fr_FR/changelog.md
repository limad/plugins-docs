# Changelog Modbus Monitor

## Version en cours de développement

### 09/11/2026

- **Sécurité et fiabilité** : les widgets installés avec le plugin proviennent d'une version figée et sont vérifiés avant installation.

### 08/11/2026

- **Sécurité et fiabilité** : les widgets ne sont téléchargés que s'ils ont changé ; vos widgets personnalisés ne sont jamais écrasés ; message plus clair dans le log en cas d'échec du téléchargement.

### 29/10/2026

- **Interface** : titre « Gestion - Modbus Monitor » sur la page du plugin ; tuiles Documentation et Community placées en dernier.

### 23/10/2026

- **Nouveautés et corrections** : traductions mises à jour.

### 17/10/2026

- **Sécurité et fiabilité** : la page du plugin fonctionne avec les protections renforcées du navigateur.

### 15/10/2026

- **Nouveautés et corrections** : widget par défaut appliqué aux nouvelles commandes ; bouton « Défaut config » pour le réappliquer à toutes les commandes d'un équipement.

### 20/09/2026

- **Nouveautés et corrections** : cycle de lecture réglable par équipement (30 s à 5 min) ; import et export d'un équipement complet (configuration et commandes) ; bouton « Informations brutes » ; tableau des commandes compact avec mode édition ; fenêtres Scan et Testeur revues, avec création d'une commande depuis le testeur ; registres voisins lus en une seule requête.
- **Sécurité et fiabilité** : l'import et l'export ne concernent que les équipements Modbus Monitor ; les fichiers importés sont supprimés après import ; une commande d'écriture affiche une erreur au lieu d'un faux succès.
