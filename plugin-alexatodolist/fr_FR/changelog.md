# Changelog Alexa - Todo List

## Version en cours de développement

### 09/11/2026

- **Sécurité et fiabilité** : le pack de widgets iso est téléchargé dans une version figée et installé seulement s'il est authentique ; aucun téléchargement s'il est déjà à jour ; une version plus récente déjà installée n'est jamais remplacée par une plus ancienne.

### 08/11/2026

- **Sécurité et fiabilité** : un seul téléchargement des widgets iso lors d'une mise à jour groupée de plusieurs plugins ; source de secours si la première est injoignable ; vos widgets personnalisés ne sont jamais écrasés ; cause exacte d'un échec dans le log.

### 29/10/2026

- **Nouveautés et corrections** : page du plugin réorganisée (titre « Gestion - Alexa - Todo List », tuiles Documentation et Communauté en dernier).

### 23/10/2026

- **Nouveautés et corrections** : traductions mises à jour.

### 17/10/2026

- **Nouveautés et corrections** : la page de l'équipement et le widget de liste fonctionnent sur les installations Jeedom récentes.

### 15/10/2026

- **Nouveautés et corrections** : les commandes utilisent les widgets iso ; nouveau bouton **Défaut config** pour les réappliquer ; la confirmation de **Supprimer tout** s'affiche de nouveau correctement.

### 14/10/2026

- **Nouveautés et corrections** : nouvelle icône du plugin ; plugin disponible en bêta sur le Market.

### 07/10/2026

- **Nouveautés et corrections** : **Supprimer tout** supprime bien les équipements du plugin ; la commande de renommage d'un élément fonctionne.

### 20/09/2026

- **Nouveautés et corrections** : **Ajouter une liste** met à jour les listes après la création.
- **Sécurité et fiabilité** : les actions qui modifient ou suppriment des données ne peuvent plus être déclenchées par un simple lien ; fichiers internes du plugin inaccessibles depuis le web.

### 10/07/2025

- **Nouveautés et corrections** : première version : listes Alexa en équipements Jeedom, ajout, renommage, coche et suppression d'éléments via Alexa Premium.
